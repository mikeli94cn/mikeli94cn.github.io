# what is web?

The Web (or World Wide Web) is a giant collection of pages, pictures, and videos that you can look at using the internet. It is like a massive, global library where every book is connected by magic threads. [1, 2, 3] 
## The Difference Between the Web and the Internet
Many people think the Web and the internet are the exact same thing, but they are actually different: [1, 4, 5] 

* The Internet: This is the physical highway. It is the giant network of wires, cables, and computers connected all over the world.
* The Web: This is the traffic driving on the highway. It is just one of the many ways we use the internet to share information. [4, 6, 7, 8] 

## How the Web Works
When you want to look at something on the Web, a few different parts work together behind the scenes: [7] 

* Web Browser: This is the app you use to open the Web, like Google Chrome, Apple Safari, or Microsoft Edge.
* URL: This is the website address that you type into the top of your browser (like ://example.com). It tells your computer exactly where to go.
* Web Server: This is a powerful computer far away that stores all the pages, images, and games for a website.
* Hyperlinks: These are just called "links" for short. They are the blue, clickable words or buttons that instantly take you from one webpage to another. [1, 2, 3, 4, 9, 10] 

## The Building Blocks of a Web Page
Webpages are built using three main ingredients: [11, 12] 

   1. HTML: This creates the basic bones and structure of the page, like the text and paragraphs.
   2. CSS: This adds the style, colors, and cool fonts to make the page look pretty.
   3. JavaScript: This adds the action, like pop-up menus, moving objects, or video game features. [7, 13, 14, 15, 16] 

## Who Invented It?
A scientist named Sir Tim Berners-Lee invented the Web in 1989. He wanted a simpler way for scientists around the world to share their research papers with each other. Today, billions of people use his invention every day to learn, play games, shop, and talk to friends. [2, 3, 10, 17, 18]

# what is the underlying principle of web?
The underlying principle of the Web is connectivity through links, also known as hypertext. [1, 2, 3] 

The main idea is that information does not have to be read in a straight line from start to finish like a normal book. Instead, any piece of information can be instantly connected to any other piece of information anywhere in the world. [4, 5, 6] 

Here is a breakdown of the core principles that make the Web work:
## 1. Decentralization (No Single Boss)

* Anyone can build a website.
* No single company controls the whole Web.
* No central computer runs everything.
* If one website crashes, the rest of the Web keeps working. [7, 8, 9, 10] 

## 2. Universality (Everyone is Welcome)

* The Web must work on any device.
* It works on phones, computers, and TVs.
* It works on any operating system like Windows, Mac, or Linux.
* Anyone can access it, no matter where they live. [11, 12, 13, 14, 15] 

## 3. Open Standards (Speaking the Same Language)
To make sure all computers can talk to each other, the Web uses free, open rules. No one has to pay to use these rules: [16, 17, 18, 19] 

* HTTP: The rules for how computers request and send webpages.
* HTML: The standard code language used to format pages so browsers can read them.
* URLs: A unique naming system so every single page has its own specific address. [20, 21, 22, 23, 24] 

## 4. Non-Linear Exploration (The Web of Links)

* You navigate by clicking links.
* You can jump from a page about space to a page about cats in one click.
* Information is organized in a web of connections, not a straight list. [25]

# how to learn web systematically?
To learn the Web systematically, you should follow a step-by-step path from how it works to how to build it. [1] 
## Phase 1: The Basics of the Web (Week 1)
Before writing code, understand the network. [2] 

* Internet vs. Web: Learn how routers, servers, and clients talk.
* HTTP/HTTPS: Understand how data requests and responses move.
* DNS: Learn how computer names turn into IP addresses. [3, 4, 5, 6, 7] 

## Phase 2: Frontend Foundations (Weeks 2–5)
Frontend is what users see on the screen. [8] 

* HTML5: Learn to structure text, images, and forms.
* CSS3: Learn colors, fonts, layouts (Flexbox/Grid), and responsive design.
* Git and GitHub: Learn to save your code and track changes. [9, 10, 11, 12, 13] 

## Phase 3: Making Things Move (Weeks 6–9)
Add logic and action to your pages. [14, 15, 16] 

* JavaScript Basics: Learn variables, loops, functions, and data types.
* DOM Manipulation: Learn how JavaScript changes HTML and CSS on the fly.
* Fetch API: Learn how to get data from other websites. [17, 18, 19, 20, 21] 

## Phase 4: Backend Foundations (Weeks 10–13)
Backend is the hidden brain that stores data. [22] 

* Server Language: Pick one language like Node.js (JavaScript) or Python.
* API Creation: Learn to build pathways for data to travel.
* Databases: Learn how to store info using SQL or MongoDB. [23, 24, 25, 26, 27] 

## How to Practice

* Do not just watch videos.
* Build a simple project after every lesson.
* Start with a personal biography page.
* Move up to a functional calculator.
* Finish with a full social media clone. [28, 29]
