# 1. The 3M computer (the famous one)

The **3M computer** was a vision for an advanced personal workstation in the early 1980s, proposed at Carnegie Mellon University (CMU). It described a workstation powerful enough for serious academic and engineering work. ([Wikipedia][1])

The three "M"s mean:

## 1. Megabyte memory

At least:

```
1 MB RAM
```

At that time, normal personal computers often had only:

```
64 KB
128 KB
256 KB
```

So 1 MB was enormous.

---

## 2. Megapixel display

A display with about:

```
1,000,000 pixels
```

For example:

```
1024 × 1024 pixels
```

This was important because GUI systems need high-resolution graphics.

---

## 3. Million Instructions Per Second

Processing speed:

```
1 MIPS
```

meaning:

```
1 million instructions per second
```

---

So:

```
3M computer

Memory:
    1 MB RAM

Display:
    1 megapixel

CPU:
    1 MIPS

Cost:
    about 1 megapenny ($10,000)
```

([Wikipedia][1])

Your question is referring to a **computer evolution model** that extends the **3U → 3K → 3M** classification. In this model, later stages are usually described as **3E** and **3T**. The exact wording varies between textbooks, but the general idea is the evolution from **human calculation tools → character computers → graphical computers → intelligent/networked computers**.

A common interpretation is:

| Era    | Main unit                          | Meaning                                               |
| ------ | ---------------------------------- | ----------------------------------------------------- |
| **3U** | User + manual tools                | Abacus, adding machine, paper and pen                 |
| **3K** | Kilo                               | KB memory, KIPS speed, character interface            |
| **3M** | Mega                               | MB memory, megapixel display, MIPS speed              |
| **3E** | Electronic / Embedded / Everywhere | Computing becomes integrated into devices             |
| **3T** | Tera / Tiny / Transparent          | Computing becomes invisible, massive, and intelligent |

Let's examine the later stages.

---
